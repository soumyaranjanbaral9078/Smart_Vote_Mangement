# SmartVote – Online Voting Management System

## 📌 Project Overview

SmartVote is a web-based Online Voting Management System developed using HTML, CSS, and JavaScript. It provides a simple and user-friendly platform to manage voters, candidates, elections, and voting activities.

The system includes separate Admin and Voter dashboards to manage election activities and allow registered voters to cast their votes.

## 🎯 Project Objectives

- Provide a user-friendly online voting interface.
- Manage voter registration and authentication.
- Manage candidates and election details.
- Allow registered voters to participate in elections.
- Prevent duplicate voting through application-level validation.
- Display election results and candidate-wise vote counts.
- Generate downloadable PDF election reports.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. Register a new voter account.
6. Login using the admin or voter account.
7. Explore the available features.

## ⚠️ Project Limitations

This project is developed for educational and demonstration purposes using frontend technologies.

- Application data is stored in browser LocalStorage and SessionStorage.
- Authentication and authorization are handled on the client side.
- Browser storage can be modified by users.
- The application is not suitable for conducting real or legally binding elections.
- A secure backend, database, server-side authentication and additional security controls are required for production use.
